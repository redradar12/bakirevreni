Bakır Evreni

Basit e-ticaret demo sitesi (statik). Supabase REST API ile ürünleri çekiyor.

Hazırla ve GitHub'a gönder:

1) Yerelde bir kez çalıştırın (PowerShell veya CMD):

   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/redradar12/bakirevreni.git
   git push -u origin main

Alternatif: `gh` CLI ile (GitHub CLI yüklüyse ve kimlik doğrulaması yapılmışsa):

   gh repo create redradar12/bakirevreni --public --source=. --remote=origin --push

Notlar:
- GitHub'a push etmek için hesabınızda yeterli yetki ve kimlik doğrulaması gereklidir.
- Eğer uzak repo mevcut değilse `gh repo create` tercih edin.
- Eğer `git push` sırasında hata alırsanız, lütfen hatayı paylaşın, yardımcı olayım.
